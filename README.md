# Glorify: test downloads

Glorify is a presentation app for church services: lyrics, scripture, videos, announcements and a stage display. This page only hosts test builds for our team. **They are not ready for live services yet.**

## Download

Get the installer from the **[latest release](https://github.com/beyondmrk/glorify-releases/releases/latest)** (Windows 10 or 11, 64-bit).

## Install

1. Download `Glorify-…-setup.exe` from the latest release.
2. Open it. Windows will say "Windows protected your PC" because the app isn't code-signed yet. Click **More info → Run anyway**.
3. Open **Glorify** from the Start menu.

Installing a newer build upgrades the app in place. Uninstall from **Settings → Apps**; your saved shows are kept.

## Reporting problems

Send what you were doing, what you expected, what happened, a screenshot or phone video if you can, and roughly what time it happened. Anything slow, confusing or ugly counts too.

## Third-party software

Glorify includes LibVLC (LGPL 2.1+) and the .NET runtime. Their licences and notices are installed with the app. The LibVLC source code for this build is attached to each release.
